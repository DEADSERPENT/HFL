## Compile `main.tex`, never a section file
The files under `sections/` are `\section` fragments: they carry no
`\documentclass` and no `\begin{document}`. Compiling one directly produces
`Undefined control sequence` at `\section` followed by a cascade of
`Missing \begin{document}` errors. In Overleaf set **Menu → Main document →
main.tex**.

## The IEEEtran class and BibTeX style
`IEEEtran.cls` and `IEEEtran.bst` are **not bundled** here. They are the
official IEEE files, provided by every LaTeX distribution and by Overleaf, so
`\documentclass{IEEEtran}` and `\bibliographystyle{IEEEtran}` resolve without a
local copy:

- **Overleaf:** compiles as-is. Upload this folder; no extra files needed.
- **TeX Live:** included in the `ieeetran` package; if missing,
  `tlmgr install ieeetran`.
- **MiKTeX:** installed on first use, or via the Package Manager (`ieeetran`).

For a fully self-contained archival copy, place the official files beside
`main.tex`:
```bash
kpsewhich IEEEtran.cls   # prints the path in your distribution
kpsewhich IEEEtran.bst
```

## Build
From inside `paper/`:
```bash
pdflatex main
bibtex   main
pdflatex main
pdflatex main
```
or, in one command:
```bash
latexmk -pdf main.tex
```
To keep build products out of the source tree:
```bash
latexmk -pdf -outdir=output main.tex
```

## Regenerating the figures
Every figure is generated by one script and every quantity in them is **read
from the project's own artefacts** — `partition_meta.json`, `dataset_meta.json`,
`hfl_config.json`, the case-id array, and the model itself. Nothing is typed in
twice, so a figure cannot drift from the system it describes:
```bash
cd figures && python make_method_figures.py
```
It writes both `.pdf` (for LaTeX) and `.png` (for eyeballing). The palette is
three hues validated for colour-vision deficiency (worst adjacent ΔE 11.0
deutan) and every colour is paired with a text label, so the figures survive
greyscale printing.
